# Radiate

Um sistema de gerenciamento de simulações feitas por um software, especificamente o fluka, que permite fazer o upload de simulações e visualizá-las em plot. São simulações de radiação no detector do lhcb, experimento do acelerador de partículas do cern.

Trabalho da matéria de Engenharia de Software do curso de Engenharia de Computação da UFRJ
